What is Google Antigravity (agy)? — Quick Overview

Start here if you are brand new to agentic AI coding.

Google Antigravity is an AI-first development platform from Google DeepMind. Instead of typing every line of code yourself, you describe your goal in plain English and act like a project director while AI agents plan the steps, edit files, run commands, and visually test your app in a browser—pausing so you stay in control.

1. Antigravity 2.0 (App)

Standalone desktop "mission control" app to chat with agents, run parallel tasks, and inspect plans & changed files side by side.

2. Antigravity IDE

AI-powered VS Code-style code editor with smart Tab autocomplete, inline edits (Ctrl+I), and red/green code diffs.

3. Antigravity CLI (agy)

Lightweight terminal command-line assistant for fast keyboard-only chats, quick project edits, and slash commands.

4. SDK & Extensions

Connects Antigravity agents to other editors (VS Code, JetBrains, Zed) or lets developers automate agents using the Python SDK.

How a task flows: 1. Share your goal → 2. Review blueprint → 3. Approve edits & commands → 4. Verify in built-in browser
